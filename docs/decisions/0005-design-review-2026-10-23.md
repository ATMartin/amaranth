# 0005 — Design review of 2026-10-23: UI direction and new milestones G–N

Date: 2026-10-23 · Status: Accepted (user's recorded design review, 14 min, plus four follow-up answers the same day)

Source material: `docs/design-review/2026-10-23/` (timestamped transcript and reference images taken from the
recording and from Granola, the app the user draws inspiration from). Tasks T22–T55 in `implementation-tasks.json`.

## What the user likes (keep as is)

- Notes with attribution; decisions and open questions sections.
- The granular, skimmable transcript; click-to-play; selecting a speaker and renaming it.
- The Recording tab (events, gaps, disk use): **no changes, out of scope.**
- Export ("sharing works great"): no changes.
- Model management sheet "with lots of information": no changes.
- The collapsible sidebar and the meeting history in it.

## Decisions

| Topic | Decision | Tasks |
|---|---|---|
| Notes attribution | Evidence links are hidden by default behind a global, persisted "Details" toggle (⌘D). | T22 |
| Topics | Removed from notes: not shown and not generated (user chose "stop generating", for faster notes). Old revisions still decode and render. | T23 |
| Your notes / scratchpad | Kept, collapsed by default. | T24 |
| Transcript noise | Default "skim" view hides gap rows (hairline + tooltip instead) and flag text; the Details toggle shows everything. Missing audio is never hidden without a trace. | T25 |
| Editable fields | Title header becomes static; rename is a context-menu action on the sidebar card. Every remaining editable field gets a visible focus ring and cursor. | T26, T28 |
| Meeting cards | Title, date, duration and one status glyph with a tooltip; no badge lines. | T27 |
| Tooltips | Every main action shows its keyboard shortcut. | T29 |
| Recorder | Defaults live in Settings; the sidebar recorder form is replaced by a toolbar Record split button and a compact recording strip; sidebar = meetings only. | T30–T34 |
| Live view | Transcript front and center while recording (never a modal); Notes tab when notes exist. | T32 |
| Transcript layout | Three columns (time · speaker · text), consecutive same-speaker rows grouped, speaker initials disc. Chat-bubble style is an optional exploration behind a setting. | T35, T37, T38 |
| Density | Smaller type scale by default with a text-size setting; lighter visual language with small icons (SF Symbols or emoji; no custom SVGs yet). | T36, T45 |
| Folders | Single-level folders managed in the sidebar with drag and drop. **Not tags**: the user explicitly does not want tags. | T39–T42 |
| Light mode | Light/dark/system appearance with a sun/moon toolbar toggle; colours from standard macOS conventions, at our discretion. | T43–T44 |
| Notes templates | User-authored section lists drive extraction; evidence checks still apply; time cost measured. | T46–T48 |
| Calendar and people | Placeholders now (data fields and header chips); a written spec for an EventKit-based integration later. | T49–T51 |
| Search | The user chose "ask anything" over meetings (local model, evidence-backed answers) as the search direction, built on the existing FTS index; the entry point is placed first. | T52–T55 |

## Explicitly not doing

- Live speaker count during a meeting: dropped after learning speakers are only found at Stop (user: "not an important change"; do not record for later).
- Tags, nested folders (single level for now).
- Accounts, profiles, spaces, invitations, plans, any cloud component.
- Copying Granola's UI exactly; the hidden-transcript recording modal in particular.
- Custom SVG icon sets (for now).

## Order

Quick wins first (Milestone G), then T21 (qualify Milestone E), then the larger UI milestones H → I → J → K → L → M → N,
then Milestone F (release qualification). The order among H–N is a recommendation. Each milestone still ends with an
independent validator pass before its commit.

**Update 2026-10-26 (user decision, after Milestone I):** the remaining order is K → M → N → J → L → T21 → F.
Two task dependencies that pointed the other way were sequencing only and were dropped: T49 no longer waits for T39,
and T52 no longer waits for T40 (notes on each task in `docs/implementation-tasks.json`). Because T21 now follows L,
L's default notes template must reproduce today's notes so T21 can still compare against baseline-v0.
